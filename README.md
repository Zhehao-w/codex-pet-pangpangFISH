# 蓝色大肥鱼

一只住在 Codex 桌面里的蓝色鲸鱼女仆。

她圆乎乎、爱吃白饭，也靠 Token 补充能量。平时会捧着空碗眼巴巴地等投喂；鼠标经过时，她会立刻叉腰、挺胸、抬头，理直气壮地表示：没吃饱不是很正常吗？

## 特点

- Codex Hatch Pet V2 格式
- 8 × 11 动画网格
- 1536 × 2288 WebP 鱼图
- 透明背景
- 包含待机、奔跑、工作、失败、等待、悬停和 16 个观察方向

## 鱼图预览

![蓝色大肥鱼 Codex Pet V2 鱼图](./spritesheet.webp)

## 安装

把 `pet.json` 和 `spritesheet.webp` 复制到：

```text
~/.codex/pets/deepseek/
```

然后重新加载 Codex，即可看到蓝色大肥鱼。
